# FulcrumGrid — Logo Kit

Official FulcrumGrid logo files in every common format and variant.

## Variants

| Variant | Use it on / for |
|---------|-----------------|
| **color** | Light backgrounds (white, light grey). Gradient mark + dark wordmark with teal "Grid". |
| **white** | Dark backgrounds (navy, photos, dark UI). All white, with a teal "Grid". |
| **black** | One-colour / mono uses — print, stamps, faxes, engraving, watermarks. Solid black. |

Each variant comes as:

- **mark** — the icon only (the rounded "F" grid mark). Use for app icons, avatars, favicons, tight spaces.
- **logo** — the full lockup (mark + "FulcrumGrid" wordmark). Use as the primary logo.

## Formats

| Folder | Format | Best for |
|--------|--------|----------|
| `svg/` | SVG (vector, self-contained — font embedded) | Web, and any resize without quality loss. **Preferred source.** |
| `pdf/` | PDF (vector) | Print, design tools (Illustrator, InDesign, Office). |
| `png/` | PNG, **transparent** background, high-res | Slides, docs, web, social — anywhere you need transparency. |
| `jpg/` | JPG (no transparency — baked background) | Places that reject PNG/SVG. color/black on white; white on navy. |

## Brand colours

- Teal `#5eead4`  ·  Indigo `#6366f1`  (mark gradient)
- Deep teal `#0d9488`  ("Grid" on light backgrounds)
- Ink navy `#0b1020`  (wordmark on light / dark background)

## Usage notes

- Keep clear space around the logo of at least the height of the mark's rounded corner.
- Don't recolour, stretch, rotate, or add effects. Pick the variant that fits the background instead.
- Minimum size: mark ~16px, full lockup ~90px wide, for legibility.
- Typeface: **Space Grotesk** (700). It's embedded in the SVGs, so they render correctly without the font installed.
