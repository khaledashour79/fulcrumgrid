Wie setzt man OKR für ein kleines Team?

OKR halten ein kleines Team fokussiert. Erfahren Sie, was sie sind, wie viele Sie setzen, wie Sie messbare Key Results schreiben und in welchem Rhythmus Sie prüfen.

9. Oktober 2026 · 6 Min. Lesezeit

Objectives and Key Results (OKR) geben einem kleinen Team ein gemeinsames Verständnis davon, worauf es in diesem Quartal ankommt und woran jeder erkennt, ob er es erreicht hat. Sie helfen besonders, wenn wenige Köpfe da sind und man sich nicht in zehn Richtungen zugleich verzetteln darf. Die Falle ist, sie als aufgehübschte To-do-Liste zu behandeln. Dieser Leitfaden erklärt, was OKR sind, wie viele man setzt, wie man messbare Key Results schreibt und welcher Rhythmus sie am Leben hält.

Was sind OKR?

OKR sind eine schlanke Methode zur Zielsetzung aus zwei Teilen. Das Objective ist eine kurze, qualitative Aussage darüber, was Sie erreichen wollen — es sollte einprägsam und ein wenig inspirierend sein. Die Key Results sind die zwei bis vier messbaren Ergebnisse, die belegen, dass Sie es erreicht haben. Trifft jedes Key Result sein Ziel, ist das Objective per Definition erfüllt. Die Methode zwingt das Team, sich vorab auf das Bild von Erfolg zu einigen, statt am Quartalsende darüber zu streiten.

Objective oder Key Result?

Beides wird ständig verwechselt, deshalb lohnt sich Strenge. Ein Objective beantwortet die Frage „Wohin wollen wir?“ und trägt keine Zahl. Ein Key Result beantwortet „Woran erkennen wir, dass wir da sind?“ und trägt immer eine Zahl. „Die erste Wahl der lokalen Kunden werden“ ist ein Objective. „Die Wiederbestellquote von 40 % auf 55 % heben“ ist ein Key Result. Eine Zeile ohne Messgröße ist kein Key Result — sie gehört entweder zum Objective oder ist eine Aufgabe.

Wie viele OKR sollte ein kleines Team setzen?

Weniger, als Sie denken. Für ein Team von fünf bis fünfzehn Personen zielen Sie auf ein bis drei Objectives mit jeweils zwei bis vier Key Results. Das ist das ganze Quartal. Ein kleines Team, das fünf Objectives setzt, hat in Wahrheit keines gesetzt, denn die knappe Ressource ist Aufmerksamkeit, nicht Ehrgeiz. Fällt das Kürzen schwer, fragen Sie, welches Objective Sie schützen würden, wenn das Quartal zusammenbräche. Dort fangen Sie an, der Rest wartet.

Wie schreibt man messbare Key Results?

Ein gutes Key Result nennt eine Messgröße, einen Ausgangswert und ein Ziel, damit später nicht darüber gestritten wird, ob es erreicht ist. Bevorzugen Sie Ergebnisse vor Aktivitäten: „10 Artikel veröffentlichen“ misst Aufwand, während „organische Anmeldungen von 120 auf 200 pro Monat steigern“ das eigentlich gewünschte Ergebnis misst. Bei ambitionierten Zielen setzen Sie die Latte so hoch, dass rund 70 % noch ein starkes Quartal sind. Erreichen Sie jedes Mal 100 % jedes Key Results, sind die Ziele zu weich und lehren das Team, tief zu stapeln.

Ein durchgerechnetes Beispiel

Hier ein Quartalssatz für ein kleines Operations-Team in einem Dienstleistungsunternehmen. Als Muster zu verstehen, nicht als Vorschrift.

  • Objective: Das Onboarding zu etwas machen, von dem neue Kunden schwärmen.
  • Key Result 1: Die durchschnittliche Zeit bis zum ersten Mehrwert von 21 auf 10 Tage senken.
  • Key Result 2: Die Onboarding-Zufriedenheit von 3,8 auf 4,5 von 5 steigern.
  • Key Result 3: Einrichtungsbezogene Support-Tickets pro Neukunde von 6 auf 2 senken.

Beachten Sie: Keines nennt eine Aufgabe. „Einen Willkommensleitfaden schreiben“ mag helfen, gehört aber ins Backlog, nicht in die Key Results.

Welcher Rhythmus hält OKR am Leben?

Setzen Sie OKR einmal pro Quartal, idealerweise in der Woche davor. Machen Sie dann wöchentlich oder alle zwei Wochen einen kurzen Check-in: Jeder Verantwortliche sagt, wo seine Key Results stehen und was sie blockiert. Am Quartalsende bewerten Sie jedes Key Result auf einer Skala von 0,0 bis 1,0, wobei 1,0 die volle Zielerreichung und 0,7 soliden Fortschritt bedeutet. Die Bewertung ist der Anlass für ein ehrliches Gespräch, keine Leistungsnote. Verbringen Sie mehr Zeit mit dem, was Sie gelernt haben, als mit der Zahl selbst.

Häufige Fallstricke

  • Zu viele OKR. Vier Objectives mit je fünf Key Results sind eine Wunschliste, kein Plan.
  • Aufgaben als Key Results getarnt. Was Sie an einem Nachmittag abhaken, ist eine Aufgabe, kein Ergebnis.
  • Tiefstapeln. Ziele, die Sie sicher erreichen, schützen niemanden und lehren nichts.
  • Setzen und vergessen. OKR, die zu Quartalsbeginn geschrieben und erst am Ende wieder geöffnet werden, waren nur Dekoration.
  • Bewertung als Urteil. Bedeutet eine niedrige Note Strafe, zielen die Leute beim nächsten Mal tief.

Halten Sie das erste Quartal bewusst klein. Setzen Sie ein Objective, halten Sie die wöchentlichen Check-ins, bewerten Sie ehrlich und justieren Sie nach. Die Gewohnheit zählt mehr als der Papierkram.

Häufige Fragen

Was ist der Unterschied zwischen Objective und Key Result?

Ein Objective ist eine kurze, qualitative Aussage über das, was Sie erreichen wollen. Ein Key Result ist ein messbares Ergebnis, das den Erfolg belegt, und trägt immer eine Zahl.

Wie viele OKR sollte ein kleines Team setzen?

Zielen Sie auf ein bis drei Objectives mit je zwei bis vier Key Results für das ganze Quartal. Ein kleines Team, das mehr setzt, hat meist keines gesetzt.

Was bedeutet ein Wert von 70 %?

Bei ambitionierten Zielen ist das Erreichen von rund 70 % Ihrer Ziele ein starkes Quartal. Schaffen Sie stets 100 %, sind die Ziele wahrscheinlich zu leicht.

Wie oft sollten wir OKR prüfen?

Setzen Sie sie einmal pro Quartal, machen Sie wöchentlich oder alle zwei Wochen einen Check-in und bewerten Sie jedes Key Result am Quartalsende von 0,0 bis 1,0.
