التكاملات

يتّصل بالأنظمة التي تشغّلها بالفعل.

يعمل FulcrumGrid جنبًا إلى جنب مع حزمة ERP والمحاسبة لديك — SAP Business One وOdoo وOracle وQuickBooks Online — ويمنح مطوّريك واجهة REST API وWebhooks وSSO/SCIM لربطه بكل ما عداه. أبقِ دفاترك حيث هي؛ وضَع عملياتك على شبكة واحدة.

تحدّث إلينا عن حزمتك استكشف التطبيقات

01 · ERP والمحاسبة

اربط نظام ERP والمحاسبة لديك.

زامِن البيانات المرجعية، وسجّل الحركات، واسحب الأرصدة وفق جدول — دون إدخال مزدوج.

SAP Business One

مزامنة ثنائية الاتجاه لشركاء الأعمال والأصناف والقيود المحاسبية — أي تغيير في أحد الطرفين يظهر في الآخر، دون إعادة إدخال. متاح عبر HR Suite وCollection وCommand Center.

Odoo

موصّل ثنائي الاتجاه يُبقي جهات الاتصال والفواتير والمدفوعات متوافقة بين Odoo والشبكة، لتقرأ عمليات التحصيل واللوحات دائمًا من الأرقام نفسها.

Oracle

اربط ماليات Oracle لبثّ الأرصدة والذمم الحيّة مباشرةً إلى Command Center — لترى الإدارة الوضع الحقيقي، لا تصدير الأسبوع الماضي.

QuickBooks Online

اربط QuickBooks Online (QBO) لمطابقة الفواتير بالمدفوعات والتسوية تلقائيًا. تبقى دفاترك في QuickBooks؛ ويختفي عناء التصدير وإعادة الاستيراد.

يشمل Command Center اتصال ERP واحدًا على Growth، واتصالات غير محدودة مع سحب مجدول على Enterprise. شاهد تكاملات Command Center ←

02 · ابنِ على الـ API

اربطه بكل ما عداه.

كل ما يمكنك فعله في التطبيقات يمكنك فعله عبر الـ API — مع بيئة اختبار للبناء بأمان.

REST API v1

واجهة REST API نظيفة ومُصدَّرة بإصدارات، بصيغة JSON متوقّعة ومصادقة برمز — اقرأ واكتب أي سجلّ يمكن لفريقك الوصول إليه في التطبيق. موثّقة بالكامل، ومتاحة على Collection Business وما فوق.

Webhooks

اشترك في الأحداث المهمّة ويرسلها FulcrumGrid إلى نقاط النهاية لديك لحظة وقوعها — لتتفاعل أنظمتك فوريًا، دون استطلاع دوري ودون تأخير.

Sandbox

بيئة اختبار كاملة تحاكي الإنتاج، بمفاتيحها وبياناتها التجريبية الخاصة — ابنِ كل تكامل وتحقّق منه بأمان قبل أن يُمسّ أي سجلّ حيّ.

سحب مجدول

حدّد وتيرة ويسحب Command Center الأرصدة والسجلات من نظام ERP لديك تلقائيًا — كل ساعة أو كل ليلة أو كما تشاء — لتبقى اللوحات محدّثة دون أي جهد.

03 · الهوية والوصول

الدخول الموحّد وإدارة الحسابات.

استخدم مزوّد الهوية الخاص بك وأدِر الأشخاص بالطريقة التي تتّبعها بالفعل.

SSO

دخول موحّد عبر مزوّد الهوية الذي تشغّله بالفعل، ليسجّل فريقك الدخول مرة واحدة ببيانات اعتماد تديرها تقنية المعلومات لديك — دون كلمات مرور إضافية. متاح على HR Suite Enterprise.

SCIM

توفير حسابات تلقائي عبر SCIM — يحصل الموظفون الجدد على الوصول الصحيح يوم مباشرتهم، ويفقده المغادرون لحظة إنهاء خدمتهم، مباشرةً من دليلك.
