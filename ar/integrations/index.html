التكاملات

يتّصل بالأنظمة التي تشغّلها بالفعل.

يعمل FulcrumGrid جنبًا إلى جنب مع حزمة ERP والمحاسبة لديك — SAP Business One وOdoo وOracle وQuickBooks Online — ويمنح مطوّريك واجهة REST API وWebhooks وSSO/SCIM لربطه بكل ما عداه. أبقِ دفاترك حيث هي؛ وضَع عملياتك على شبكة واحدة.

تحدّث إلينا عن حزمتك استكشف التطبيقات

01 · ERP والمحاسبة

اربط نظام ERP والمحاسبة لديك.

زامِن البيانات المرجعية، وسجّل الحركات، واسحب الأرصدة وفق جدول — دون إدخال مزدوج.

SAP Business One

مزامنة ثنائية الاتجاه لشركاء الأعمال والأصناف والقيود المحاسبية — أي تغيير في أحد الطرفين يظهر في الآخر، دون إعادة إدخال. متاح عبر منصة الموارد البشرية ومنصة تحصيل الديون ولوحة التحكم للتنفيذيين.

Odoo

رحّل رواتب منصة الموارد البشرية إلى Odoo كقيود يومية مسوّدة، وادفع المدفوعات المحصّلة والشيكات المحصّلة من منصة تحصيل الديون كمدفوعات مسوّدة، وأبقِ لوحات لوحة التحكم للتنفيذيين تقرأ من الأرقام نفسها — اتصال ثنائي الاتجاه، دون إعادة إدخال.

Oracle

تبثّ لوحة التحكم للتنفيذيين أرصدة Oracle الحيّة إلى لوحاتك؛ وترحّل منصة الموارد البشرية قيود الرواتب عبر Oracle Integration (OIC) وOracle Fusion (ERP Cloud)؛ وترحّل منصة تحصيل الديون المدفوعات المحصّلة كإيصالات ذمم مدينة في Oracle Fusion.

QuickBooks Online

اربط QuickBooks Online (QBO) لمطابقة الفواتير بالمدفوعات والتسوية تلقائيًا. تبقى دفاترك في QuickBooks؛ ويختفي عناء التصدير وإعادة الاستيراد.

يشمل لوحة التحكم للتنفيذيين اتصال ERP واحدًا على النمو، واتصالات غير محدودة مع سحب مجدول على المؤسسات. شاهد تكاملات لوحة التحكم للتنفيذيين ←

02 · ابنِ على الـ API

اربطه بكل ما عداه.

كل ما يمكنك فعله في التطبيقات يمكنك فعله عبر الـ API — مع بيئة اختبار للبناء بأمان.

REST API v1

واجهة REST API نظيفة ومُصدَّرة بإصدارات، بصيغة JSON متوقّعة ومصادقة برمز — اقرأ واكتب أي سجلّ يمكن لفريقك الوصول إليه في التطبيق. موثّقة بالكامل: واجهة REST API لمنصة تحصيل الديون على باقة الأعمال وما فوق، وواجهة الشركاء البرمجية لمنصة الموارد البشرية على باقة المؤسسات.

Webhooks

اشترك في الأحداث المهمّة ويرسلها FulcrumGrid إلى نقاط النهاية لديك لحظة وقوعها — لتتفاعل أنظمتك فوريًا، دون استطلاع دوري ودون تأخير.

Sandbox

بيئة اختبار كاملة تحاكي الإنتاج، بمفاتيحها وبياناتها التجريبية الخاصة — ابنِ كل تكامل وتحقّق منه بأمان قبل أن يُمسّ أي سجلّ حيّ.

سحب مجدول

حدّد وتيرة ويسحب لوحة التحكم للتنفيذيين الأرصدة والسجلات من نظام ERP لديك تلقائيًا — كل ساعة أو كل ليلة أو كما تشاء — لتبقى اللوحات محدّثة دون أي جهد.

03 · الهوية والوصول

الدخول الموحّد وإدارة الحسابات.

استخدم مزوّد الهوية الخاص بك وأدِر الأشخاص بالطريقة التي تتّبعها بالفعل.

SSO

دخول موحّد عبر مزوّد الهوية الذي تشغّله بالفعل، ليسجّل فريقك الدخول مرة واحدة ببيانات اعتماد تديرها تقنية المعلومات لديك — دون كلمات مرور إضافية. متاح على منصة الموارد البشرية ومنصة تحصيل الديون (المؤسسات).

SCIM

توفير حسابات تلقائي عبر SCIM — يحصل الموظفون الجدد على الوصول الصحيح يوم مباشرتهم، ويفقده المغادرون لحظة إنهاء خدمتهم، مباشرةً من دليلك.

04 · التنبيهات والمراسلة

ادفع الإشارة إلى حيث يكون فريقك أصلًا.

أرسِل ما يهمّ إلى القنوات التي يتابعها فريقك فعلًا — دون لوحة إضافية تتفقّدها.

Slack وMicrosoft Teams

تنشر لوحة التحكم للتنفيذيين ملخّصًا للبنود المتأخّرة والأحداث المهمّة إلى قناة Slack أو Teams عبر webhook وارد — ليرى فريقك ما يحتاج إلى انتباه دون فتح التطبيق.

تذكيرات متعدّدة القنوات

تصل منصة تحصيل الديون إلى كل مدين على القناة التي يردّ عليها فعلًا، وتُرسَل تلقائيًا وفق جدول التذكير الذي تحدّده — لتنطلق المتابعات دون أن يطارد أحدٌ يدويًا.

05 · التعلّم

أدخِل كتالوج التعلّم لديك.

اربط مكتبات الدورات التي يستخدمها فريقك أصلًا، وأسنِد منها، وتتبّع الإتمام داخل منصة الموارد البشرية.

Udemy Business

زامِن كتالوج Udemy Business داخل منصة الموارد البشرية، وأسنِد الدورات للموظفين والمديرين، وسجّل الإتمام في سجلّ تعلّمهم — ثم اقترح الدورات مباشرةً داخل التقييمات وخطط التطوير.

LinkedIn Learning وCoursera

اربط LinkedIn Learning وCoursera for Business بالطريقة نفسها — تصفّح كتالوج المزوّد، وأسنِد دورة، ودع الإتمام يتدفّق تلقائيًا، مع شهادة في ملف الموظف.
